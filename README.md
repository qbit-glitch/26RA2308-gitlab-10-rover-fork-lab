# Kestrel-1 rover

Firmware (C) for the Kestrel-1 rover. Everybody is welcome to contribute.

| Folder | What is in it |
|---|---|
| src/ | C firmware: motion commands and the ultrasonic range reader |
| data/ | calibration logs recorded on the test track |

## How to contribute

1. Fork this repository on GitHub and clone your fork.
2. Add the original repository as the remote `upstream` and bring your fork up to date before you start.
3. Make your change on a new branch, never on `main`, and push that branch to your fork.
4. The first change everybody makes is to add their name to `CONTRIBUTORS.md`.
